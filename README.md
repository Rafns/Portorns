# Rafael Nandana S - Portfolio (Portorns)

Personal portfolio of **Rafael Nandana S**, Undergraduate Computer Science student at BINUS University specializing in Artificial Intelligence, Machine Learning, and Software Engineering.

## 🚀 Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4
- **Animation**: Motion & WebGL / Canvas Animations
- **Icons**: Lucide React

## 📦 Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run development server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```

4. **Preview production build**:
   ```bash
   npm run preview
   ```
